# Debt Tracker 💳

Мобильный трекер кредиток, рассрочек и кредитов. Данные сохраняются локально на телефоне.

## Возможности

- Добавление кредиток, рассрочек, кредитов и других долгов
- Отслеживание остатка и прогресса погашения
- Сводка «К оплате в месяц» — сумма всех ежемесячных платежей
- Внесение платежей (минимальный или полное погашение)
- Напоминания по дате следующего платежа
- Экспорт / импорт данных (резервная копия)
- Работает как приложение на iPhone (PWA)

## Как залить на GitHub Pages

### 1. Создай репозиторий на GitHub

1. Зайди на [github.com/new](https://github.com/new)
2. Название: `creditki` (или любое)
3. Public → Create repository

### 2. Загрузи проект

```bash
cd "C:\Users\safin\OneDrive\Рабочий стол\Практики-хлам\creditki"
git init
git add .
git commit -m "Debt Tracker — мобильный трекер долгов"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/creditki.git
git push -u origin main
```

### 3. Включи GitHub Pages

1. Репозиторий → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **/ (root)**
4. Save

Через 1–2 минуты сайт будет доступен по адресу:
`https://ТВОЙ_НИК.github.io/creditki/`

## Как добавить на главный экран iPhone

1. Открой сайт в **Safari** (важно — не Chrome)
2. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Выбери **«На экран Домой»**
4. Назови приложение (например «Долги») → **Добавить**

Готово — иконка появится на рабочем столе и будет открываться как отдельное приложение.

## Локальный запуск

Просто открой `index.html` в браузере, или:

```bash
npx serve .
```

## Структура

```
creditki/
├── index.html      — разметка
├── style.css       — стили (mobile-first)
├── app.js          — логика + localStorage
├── manifest.json   — PWA манифест
└── icons/          — иконки приложения
```

## Типы долгов

| Тип | Для чего |
|-----|----------|
| 💳 Кредитная карта | Кредитки с мин. платежом |
| 🛍️ Рассрочка | Фиксированный платёж в месяц |
| 🏦 Кредит | Банковский кредит |
| 📄 Другое | Любые другие обязательства |

Данные хранятся в `localStorage` браузера и не отправляются никуда.
